BBLIT Viewer - levels folder / cartella dei livelli
===================================================

ENGLISH
No game data comes with the viewer: it reads the levels of your own copy of
Bugs Bunny: Lost in Time for PC. The PlayStation version is not supported.

Copy the .bze files from the game's Datas\bze folder (on the CD, or in the
installation folder) into this folder. All of them, or only some: the levels
without a file show greyed out in the Load level menu.

Or leave them where they are: in the viewer, General options -> Levels
folder, pick the game folder or its Datas\bze. The choice is remembered.

Without levels the viewer opens on a page that explains this, with buttons
to open this folder or choose another one. The files are only read, never
changed.

ITALIANO
Il viewer non contiene dati del gioco: legge i livelli della tua copia di
Bugs Bunny: Lost in Time per PC. La versione PlayStation non e' supportata.

Copia in questa cartella i file .bze della cartella Datas\bze del gioco (sul
CD, o nella cartella di installazione). Tutti, o solo alcuni: i livelli
senza file compaiono in grigio nel menu Carica livello.

Oppure lasciali dove sono: nel viewer, Opzioni generali -> Cartella dei
livelli, scegli la cartella del gioco o la sua Datas\bze. La scelta viene
ricordata.

Senza livelli il viewer si apre su una pagina che spiega tutto questo, con i
pulsanti per aprire questa cartella o sceglierne un'altra. I file vengono
solo letti, mai modificati.
