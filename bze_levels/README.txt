BBLIT Viewer - levels folder
============================

No game data comes with the viewer: it reads the levels of your own copy of
Bugs Bunny: Lost in Time for PC. The PlayStation version is not supported.

Copy the .bze files from the game's Datas\bze folder (on the CD, or in the
installation folder) into this folder. All of them, or only some: the levels
without a file show greyed out in the Load level menu.

Or leave them where they are: in the viewer, General options -> Levels
folder, pick the game folder or its Datas\bze. The choice is remembered.

Without levels the viewer opens on a page that explains this, with buttons
to open this folder or choose another one. The files are only read, never
changed.
